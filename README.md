# BioBrew Website

Static frontend for the BioBrew Rice Beer biotechnology project.

## GitHub Pages

1. Create a GitHub repository, e.g. `biobrew`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the Pages URL.

No backend is required.

## Important
The site is written as an academic project/prototype. Replace the team-role placeholders with your actual member names if desired.
